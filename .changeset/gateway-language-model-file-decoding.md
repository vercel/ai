Extend the opt-in streaming decoding of large images to files generated by language models.

With `providerOptions.gateway.experimental_streamingImageDecoding` set to `true`, `doGenerate` of a gateway language model now decodes canonical base64 files of at least 64 KiB (`content[*].data.data`, e.g. images from `generateText`) while reading the response and returns them as `Uint8Array`. Smaller files and strings that are not canonical base64 stay strings. Streaming is not affected. As for image models, the client option is not forwarded to the service.
