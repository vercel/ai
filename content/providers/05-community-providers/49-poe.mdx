# Poe

[Poe](https://poe.com) provides access to models from Anthropic, OpenAI, Google, and other providers through a single API key. The `ai-sdk-provider-poe` community provider connects these models to the AI SDK.

Get an API key from [Poe API keys](https://poe.com/api/keys) and browse available models in the [Poe model catalog](https://poe.com/api/models).

## Setup

The Poe provider is available in the `ai-sdk-provider-poe` module. You can install it with:

## Provider Instance

To create a Poe provider instance, use the `createPoe` function:

```typescript
import { createPoe } from 'ai-sdk-provider-poe';

const poe = createPoe({
  apiKey: 'YOUR_POE_API_KEY',
});
```

You can also use the default `poe` export, which reads from the `POE_API_KEY` environment variable:

```typescript
import { poe } from 'ai-sdk-provider-poe';
```

## Language Models

Pass a model ID from the Poe model catalog. A provider prefix, such as `anthropic/`, is optional. Routing uses the model's `supported_endpoints` metadata, with a bundled catalog that refreshes from `/v1/models` at runtime. A prefix does not force a particular API endpoint.

```typescript
// Anthropic models
const claude = poe('anthropic/claude-sonnet-4');

// OpenAI models
const gpt = poe('openai/gpt-5.4');

// Google models (via OpenAI-compatible endpoint)
const gemini = poe('google/gemini-3.1-pro');
```

## Examples

### `generateText`

```typescript
import { poe } from 'ai-sdk-provider-poe';
import { generateText } from 'ai';

const { text } = await generateText({
  model: poe('anthropic/claude-sonnet-4'),
  prompt: 'What is Poe?',
});

console.log(text);
```

### `streamText`

```typescript
import { poe } from 'ai-sdk-provider-poe';
import { streamText } from 'ai';

const result = streamText({
  model: poe('openai/gpt-5.4'),
  prompt: 'Write a short story about AI.',
});

for await (const chunk of result.textStream) {
  console.log(chunk);
}
```
