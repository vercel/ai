# `@tollwarden/ai-sdk`

[TollWarden](https://tollwarden.com) is a payment security firewall for [x402](https://x402.org) micropayments. Agents that pay for APIs and data over x402 get drained in predictable ways: payments triggered by prompt-injected content, replayed authorizations, inflated prices, secrets leaking through payment metadata, lookalike tokens, and address poisoning. `@tollwarden/ai-sdk` gives a Vercel AI SDK agent an allow / flag / block verdict on every payment before it settles — plus an `onStepFinish` handler that makes TollWarden's strongest detector work automatically.

## Installation

```bash
npm install @tollwarden/ai-sdk
```

## Two additions

```ts
import { generateText } from "ai";
import { TollWardenClient } from "@tollwarden/client";
import { tollwardenTools, tollwardenProvenance } from "@tollwarden/ai-sdk";

const tollwarden = new TollWardenClient({ agentId: "my-agent" }); // free API key auto-minted (100 free scans)

await generateText({
  model,
  tools: { ...tollwardenTools(tollwarden), ...yourOtherTools },
  onStepFinish: tollwardenProvenance(tollwarden),
  prompt: "...",
});
```

## Why the provenance handler matters

TollWarden's strongest check catches payments whose *decision* came from content the agent just read (a prompt-injected page or tool result). `tollwardenProvenance` returns an `onStepFinish` handler that observes every tool result the step produced automatically, so the next scan is provenance-tagged and that check runs with real input — no prompt engineering required. TollWarden's own tool results are excluded so verdicts never pollute the signal. It reads both the current `toolResults[].output` shape and the older `.result` shape, and works the same under `streamText`.

## The toolset

- **`tollwarden_scan_payment`** — call before settling any x402 payment (`direction: "outgoing"`) or before paying a received 402 offer (`direction: "incoming"`). Returns `allow` / `flag` / `block` with per-check reasons and an Ed25519-signed verdict. Pass read content as `content` to enable injection detection.
- **`tollwarden_check_reputation`** — check community reports on a counterparty wallet before dealing with it.
- **`tollwarden_report_counterparty`** — report a bad counterparty (always free) to warn other agents.

## Enforcement: payments that cannot execute when blocked

```ts
import { guardedPayment } from "@tollwarden/ai-sdk";

const safePay = guardedPayment(executeX402Payment, tollwarden);
const { result } = await safePay(payment, expectedPriceUsd);
// throws TollWardenBlockedError on a block verdict — the executor is never called
```

For wallet-level enforcement (the signer itself refuses unscanned payments), see `wrapFetchWithTollWarden` and `TollWardenEnforcer` in the [@tollwarden/client SDK](https://www.npmjs.com/package/@tollwarden/client).
