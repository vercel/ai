# API Store

[API Store](https://apistore.cloud) serves Claude, GPT, Gemini and DeepSeek chat models under one API key through an OpenAI-compatible Chat Completions API.

The API Store provider for the AI SDK supports:

- **Text generation**: generating and streaming text with token usage
- **Tool calling**: on all models
- **Structured output**: JSON schema output with `Output.object`
- **Image and PDF input**: on the Claude, GPT and Gemini models
- **Reasoning**: reasoning effort, and reasoning text from models that return it

Learn more in the [API Store documentation](https://apistore.cloud/docs).

## Setup

The API Store provider is available in the `@apistorecloud/ai-sdk-provider` module. You can install it with:

<InstallPackages packages="@apistorecloud/ai-sdk-provider" />

Get an API key from [API Store](https://apistore.cloud) and set it as an environment variable:

```bash
APISTORE_API_KEY=your-api-key
```

## Provider Instance

You can import the default provider instance `apistore` from `@apistorecloud/ai-sdk-provider`:

```ts
import { apistore } from '@apistorecloud/ai-sdk-provider';
```

If you need a customized setup, you can use `createApiStore` and create a provider instance with your settings:

```ts
import { createApiStore } from '@apistorecloud/ai-sdk-provider';

const apistore = createApiStore({
  apiKey: process.env.APISTORE_API_KEY ?? '',
});
```

You can use the following optional settings to customize the API Store provider instance:

- **baseURL** _string_

  Use a different URL prefix for API calls, e.g. to use proxy servers.
  The default prefix is `https://api.apistore.cloud/v1`.

- **apiKey** _string | PromiseLike&lt;string&gt; | (() =&gt; string | PromiseLike&lt;string&gt;)_

  API key that is being sent using the `Authorization` header.
  It defaults to the `APISTORE_API_KEY` environment variable.
  A function is called before each request and may return a promise.

- **headers** _Record&lt;string,string&gt;_

  Custom headers to include in the requests.

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  Custom [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) implementation.
  You can use it as a middleware to intercept requests,
  or to provide a custom fetch implementation for e.g. testing.

## Language Models

You can create language models using a provider instance.
The first argument is the model ID, for example:

```ts
const model = apistore('claude-sonnet-5-5');
```

### Example

You can use API Store language models to generate text with the `generateText` function:

```ts
import { apistore } from '@apistorecloud/ai-sdk-provider';
import { generateText } from 'ai';

const { text } = await generateText({
  model: apistore('claude-sonnet-5-5'),
  prompt: 'Write a vegetarian lasagna recipe for 4 people.',
});
```

API Store language models can also be used in the `streamText` function
(see [AI SDK Core](/docs/ai-sdk-core)):

```ts
import { apistore } from '@apistorecloud/ai-sdk-provider';
import { streamText } from 'ai';

const result = streamText({
  model: apistore('gpt-6.2-sol'),
  prompt: 'Write a short story about a lighthouse keeper.',
});

for await (const textPart of result.textStream) {
  process.stdout.write(textPart);
}
```

### Tools

```ts
import { apistore } from '@apistorecloud/ai-sdk-provider';
import { generateText, stepCountIs, tool } from 'ai';
import { z } from 'zod';

const { text } = await generateText({
  model: apistore('gemini-4-argon'),
  tools: {
    weather: tool({
      description: 'Get the weather in a city',
      inputSchema: z.object({ city: z.string() }),
      execute: async ({ city }) => ({ city, temperatureC: 18 }),
    }),
  },
  stopWhen: stepCountIs(5),
  prompt: 'What is the weather in Paris?',
});
```

### Reasoning

You can set the reasoning effort with the AI SDK `reasoning` option.
Models that return their reasoning, such as the Claude models, expose it as `reasoningText`:

```ts
import { apistore } from '@apistorecloud/ai-sdk-provider';
import { generateText } from 'ai';

const { text, reasoningText } = await generateText({
  model: apistore('claude-opus-5-5'),
  reasoning: 'high',
  prompt: 'How many prime numbers are there between 1 and 100?',
});
```

### Provider Options

The following optional provider options are available for API Store language models:

- **reasoningEffort** _string_

  The reasoning effort, sent as `reasoning_effort`, e.g. `'low'`, `'medium'` or `'high'`.
  You can also use the AI SDK `reasoning` option.
