# Supermemory

[Supermemory](https://supermemory.ai) is a memory platform that gives agents persistent, long-term memory across conversations.
The [`@supermemory/tools`](https://www.npmjs.com/package/@supermemory/tools) package adds it to the AI SDK in two ways:

- **Middleware**: `withSupermemory` wraps a model you have already configured. Before each call it loads the user's profile (and, optionally, memories relevant to the latest message) into the prompt, and afterwards it saves the conversation.
- **Memory tools**: `supermemoryTools` returns a standard AI SDK tool set that lets the model search, add and forget memories, read the user's profile, and manage documents.

Every call reads and writes one **namespace**, usually one per end user. The package calls the Supermemory v5 API and works with AI SDK 5, 6 and 7.

## Setup

The Supermemory integration is available in the `@supermemory/tools` module. You can install it with:

<InstallPackages packages="@supermemory/tools" />

Get an API key from the [Supermemory Console](https://console.supermemory.ai) and set it as `SUPERMEMORY_API_KEY`.

## Middleware

Wrap any AI SDK model with `withSupermemory`. Both options are required: `namespace` identifies whose memories to use and `id` identifies the conversation.

```ts
import { generateText } from 'ai';
import { withSupermemory } from '@supermemory/tools/ai-sdk';
import { openai } from '@ai-sdk/openai';

const modelWithMemory = withSupermemory(openai('gpt-5'), {
  namespace: 'user-123',
  id: 'conversation-456',
});

const result = await generateText({
  model: modelWithMemory,
  messages: [{ role: 'user', content: 'What do you know about me?' }],
});
```

By default the middleware injects the user's profile (`mode: 'profile'`) and saves new conversations (`addMemory: 'always'`).
Set `mode: 'query'` to search memories based on the user's message, `mode: 'full'` to do both, or `addMemory: 'never'` to only read.
The API key is read from `SUPERMEMORY_API_KEY`, or can be passed with the `apiKey` option.

## Memory Tools

`supermemoryTools` returns the tools `searchMemories`, `addMemory`, `getProfile`, `documentList`, `documentAdd`, `documentDelete` and `memoryForget`.
Pass them to `generateText`, `streamText` or `ToolLoopAgent`:

```ts
import { generateText, isStepCount } from 'ai';
import { openai } from '@ai-sdk/openai';
import { supermemoryTools } from '@supermemory/tools/ai-sdk';

const result = await generateText({
  model: openai('gpt-5'),
  prompt: 'Remember that my name is Alice',
  tools: supermemoryTools(process.env.SUPERMEMORY_API_KEY!, {
    namespace: 'user-123',
  }),
  stopWhen: isStepCount(5),
});
```

Individual tools such as `searchMemoriesTool` and `addMemoryTool` are also exported if you only want some of them.

<Note>
  The Memory Router (a provider `baseUrl` under
  `https://api.supermemory.ai/v3/`) uses the legacy v3 API, which is deprecated
  and shuts down on December 31, 2026. Use `withSupermemory` instead. If you are
  on `@supermemory/tools` 2.x, see the [3.0 upgrade
  guide](https://supermemory.ai/docs/migration/tools-v3-upgrade).
</Note>
