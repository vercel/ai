# Wallaby Provider

The [Wallaby AI SDK provider](https://www.npmjs.com/package/wallaby-ai-provider) lets you use Moonshot AI's Kimi models through Wallaby's OpenAI-compatible endpoint, with one prepaid USD balance and per-token itemized billing.

## Supported Models

- `kimi-k3.1-pro` — lead reasoning model: 1M token context, tool calling, text and image input, reasoning effort control (`low`, `high`, `max`)
- `kimi-k3.1-pro-highspeed` — high-speed variant of the lead model
- `kimi-k3` — open-weight reasoning model

## Setup

You can install the Wallaby provider with:

<InstallPackages packages="wallaby-ai-provider" />

## Provider Instance

Import the default `wallaby` instance, or create a custom one with `createWallaby`:

```ts
import { wallaby, createWallaby } from 'wallaby-ai-provider';

// Default instance: reads WALLABY_API_KEY and uses Wallaby's endpoint
// Custom instance:
const custom = createWallaby({
  apiKey: '<your-wallaby-key>',
  baseURL: 'https://api.wallabytoken.com/v1',
});
```

## Basic Usage

Get your API key from [wallabytoken.com](https://wallabytoken.com) ($0.50 trial credit, no card required).

```bash
# .env
WALLABY_API_KEY=your-wallaby-api-key
```

```typescript
import { wallaby } from 'wallaby-ai-provider';
import { generateText } from 'ai';

const { text } = await generateText({
  model: wallaby('kimi-k3.1-pro'),
  prompt: 'Explain what an OpenAI-compatible endpoint is in one sentence.',
});

console.log(text);
```
