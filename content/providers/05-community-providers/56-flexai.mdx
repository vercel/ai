# FlexAI Provider

[@flexai/ai-sdk-provider](https://github.com/flexaihq/ai-sdk-flexai) contains language model support for [FlexAI](https://flex.ai), which serves open-weight models such as DeepSeek, GLM, Gemma, Llama, Qwen and gpt-oss behind an OpenAI-compatible API.

API keys can be obtained from the [FlexAI Console](https://flex.ai).

## Setup

The FlexAI provider is available via the `@flexai/ai-sdk-provider` module. You can install it with:

<InstallPackages packages="@flexai/ai-sdk-provider" />

### Environment variables

Create a `.env` file with a `FLEXAI_API_KEY` variable.

## Provider Instance

You can import the default provider instance `flexai` from `@flexai/ai-sdk-provider`:

```ts
import { flexai } from '@flexai/ai-sdk-provider';
```

If you need a customized setup, you can import `createFlexAI` from `@flexai/ai-sdk-provider` and create a provider instance with your settings:

```ts
import { createFlexAI } from '@flexai/ai-sdk-provider';

const flexai = createFlexAI({
  // Optional settings
});
```

You can use the following optional settings to customize the FlexAI provider instance:

- **baseURL** _string_

  Use a different URL prefix for API calls, e.g. to use proxy servers.
  The default prefix is `https://api.flex.ai/v1`.

- **apiKey** _string_

  API key that is being sent using the `Authorization` header.
  It defaults to the `FLEXAI_API_KEY` environment variable.

- **headers** _Record&lt;string,string&gt;_

  Custom headers to include in the requests.

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  Custom [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) implementation.
  Defaults to the global `fetch` function.

- **includeUsage** _boolean_

  Request token usage on streamed responses. Defaults to `true`, because
  FlexAI reports usage on a stream only when `stream_options.include_usage`
  is sent.

- **supportsStructuredOutputs** _boolean_

  Send a strict `json_schema` response format for schema-constrained
  requests. Defaults to `true`.

## Language Models

You can create language models using a provider instance:

```ts
import { flexai } from '@flexai/ai-sdk-provider';
import { generateText } from 'ai';

const { text } = await generateText({
  model: flexai('DeepSeek-V4-Flash-0731'),
  prompt: 'Write a vegetarian lasagna recipe for 4 people.',
});
```

FlexAI language models can also be used in the `streamText` function:

```ts
import { flexai } from '@flexai/ai-sdk-provider';
import { streamText } from 'ai';

const result = streamText({
  model: flexai('DeepSeek-V4-Flash-0731'),
  prompt: 'Write a haiku about GPUs.',
});

for await (const chunk of result.textStream) {
  process.stdout.write(chunk);
}
```

<Note>
  FlexAI requires the canonical model id — the bare model name as returned by
  `GET /v1/models`, with no organisation prefix. Use `'gemma-4-31b-it'`, not
  `'google/gemma-4-31b-it'`.
</Note>

## Embedding Models

You can create models that call the FlexAI embeddings API using the `.embeddingModel()` factory method:

```ts
import { flexai } from '@flexai/ai-sdk-provider';
import { embed } from 'ai';

const { embedding } = await embed({
  model: flexai.embeddingModel('bge-m3'),
  value: 'sunny day at the beach',
});
```

<Note>
  Capabilities are per-model rather than provider-wide. Forced tool choice is
  best-effort rather than constrained decoding, and strict `json_schema` is
  supported on a subset of models — those that do not support it reject the
  request rather than silently ignoring it. See the
  [README](https://github.com/flexaihq/ai-sdk-flexai#capabilities-vary-by-model)
  for the measured per-model matrix.
</Note>
