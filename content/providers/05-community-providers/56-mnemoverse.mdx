# Mnemoverse

[Mnemoverse](https://mnemoverse.com) provides persistent long-term memory for AI agents. The [`@mnemoverse/ai-sdk`](https://www.npmjs.com/package/@mnemoverse/ai-sdk) package gives your agents memory tools for `generateText`, `streamText`, and `ToolLoopAgent` across sessions and applications.

Features include:

- Persistent memory tools: agents save information users share and recall it in future conversations
- Learns from outcomes: rating a recalled memory as helpful or misleading re-ranks what comes back next
- Shared memory rooms: multiple users and agents can share a unified memory context
- Full TypeScript support across AI SDK versions

## Setup

Sign up and obtain your API key from the [Mnemoverse console](https://console.mnemoverse.com/sign-up).

Set the API key in your environment:

```bash
export MNEMOVERSE_API_KEY=your-api-key
```

## Creating Memory Tools

Initialize Mnemoverse tools using `createMnemoverseTools`:

```ts
import { createMnemoverseTools, SERVER_INSTRUCTIONS } from '@mnemoverse/ai-sdk';

const memory = await createMnemoverseTools({
  apiKey: process.env.MNEMOVERSE_API_KEY,
});
```

## Basic Usage

### generateText

Pass `memory.tools` and `SERVER_INSTRUCTIONS` into `generateText`:

```ts
import { generateText, stepCountIs } from 'ai';
import { createMnemoverseTools, SERVER_INSTRUCTIONS } from '@mnemoverse/ai-sdk';

const memory = await createMnemoverseTools({
  apiKey: process.env.MNEMOVERSE_API_KEY,
});

const { text } = await generateText({
  model: 'openai/gpt-4o',
  system: SERVER_INSTRUCTIONS,
  tools: memory.tools,
  stopWhen: stepCountIs(5),
  prompt: 'I switched to Neovim. Remember that.',
});

console.log(text);

await memory.close();
```

### ToolLoopAgent

Use Mnemoverse memory tools with `ToolLoopAgent`:

```ts
import { ToolLoopAgent } from 'ai';
import { createMnemoverseTools, SERVER_INSTRUCTIONS } from '@mnemoverse/ai-sdk';

const memory = await createMnemoverseTools({
  apiKey: process.env.MNEMOVERSE_API_KEY,
});

const agent = new ToolLoopAgent({
  model: 'openai/gpt-4o',
  instructions: SERVER_INSTRUCTIONS,
  tools: memory.tools,
});

const result = await agent.generate({
  prompt: 'What editor did I say I switched to?',
});

console.log(result.text);

await memory.close();
```
