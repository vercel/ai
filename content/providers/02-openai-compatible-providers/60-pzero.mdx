# PZERO Provider

[PZERO](https://pzero.studio) provides access to language models through an OpenAI-compatible Chat Completions API. You can use it with the AI SDK through the `@ai-sdk/openai-compatible` module.

## Setup

Install the OpenAI Compatible provider:

<Tabs items={['pnpm', 'npm', 'yarn', 'bun']}>
  <Tab>
    <Snippet text="pnpm add @ai-sdk/openai-compatible" dark />
  </Tab>
  <Tab>
    <Snippet text="npm install @ai-sdk/openai-compatible" dark />
  </Tab>
  <Tab>
    <Snippet text="yarn add @ai-sdk/openai-compatible" dark />
  </Tab>
  <Tab>
    <Snippet text="bun add @ai-sdk/openai-compatible" dark />
  </Tab>
</Tabs>

## Provider Instance

Create a PZERO provider instance with `createOpenAICompatible`:

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';

const pzero = createOpenAICompatible({
  name: 'pzero',
  apiKey: process.env.PZERO_API_KEY,
  baseURL: 'https://api.pzero.studio/v1',
});
```

Use the `/v1` API root for `baseURL`; the provider appends `/chat/completions` when it sends a request.

<Note>
  Create a `pzero_` API key and fund its prepaid balance in the [PZERO
  Studio](https://pzero.studio/agents), then set the `PZERO_API_KEY` environment
  variable to that key.
</Note>

## Language Models

Use a live text model ID from the public [`GET /v1/models` catalog](https://api.pzero.studio/v1/models). Pass the catalog ID directly to the provider:

```ts
const model = pzero('deepseek-v4-flash');
```

### Example

Generate text with PZERO and the `generateText` function:

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';
import { generateText } from 'ai';

const pzero = createOpenAICompatible({
  name: 'pzero',
  apiKey: process.env.PZERO_API_KEY,
  baseURL: 'https://api.pzero.studio/v1',
});

const { text } = await generateText({
  model: pzero('deepseek-v4-flash'),
  prompt: 'Hello from PZERO',
});

console.log(text);
```

See the [PZERO Chat Completions documentation](https://docs.pzero.studio/agents/chat) for API details.
