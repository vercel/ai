# AssemblyAI Provider

The [AssemblyAI](https://assemblyai.com/) provider contains transcription model support for the AssemblyAI transcription API and speech model support for the AssemblyAI text-to-speech API.
AssemblyAI models are not currently available through [AI Gateway](https://vercel.com/ai-gateway/models), so the opening example uses `@ai-sdk/assemblyai` directly. See [Using AI Gateway](#using-ai-gateway) below for supported alternatives.

```ts
import { transcribe } from 'ai';
import { assemblyai } from '@ai-sdk/assemblyai';
import { readFile } from 'node:fs/promises';

const { text } = await transcribe({
  model: assemblyai.transcription('assemblyai-stt-3-7'),
  audio: await readFile('audio.mp3'),
});

console.log(text);
```

The example transcribes an `audio.mp3` file from your project.

## Using AI Gateway

The current [AI Gateway model catalog](https://vercel.com/ai-gateway/models) does not list AssemblyAI models. Use `@ai-sdk/assemblyai` for the APIs on this page. To use other transcription models through Gateway, install `ai` and configure a Gateway API key:

<InstallPackages packages="ai" />

Set an [AI Gateway API key](https://vercel.com/docs/ai-gateway/getting-started) in your environment:

```bash
export AI_GATEWAY_API_KEY=your_api_key_here
```

Vercel deployments can also use [OIDC authentication](/providers/ai-sdk-providers/ai-gateway#oidc-authentication-vercel-deployments).
See the [Gateway documentation](/providers/ai-sdk-providers/ai-gateway) for supported models and APIs.

## Using `@ai-sdk/assemblyai`

For direct access to AssemblyAI, install `ai` and `@ai-sdk/assemblyai`:

<InstallPackages packages="ai @ai-sdk/assemblyai" />

Set your AssemblyAI API credential in the `ASSEMBLYAI_API_KEY` environment variable:

```bash
export ASSEMBLYAI_API_KEY=your_api_key_here
```

## Provider Instance

You can import the default provider instance `assemblyai` from `@ai-sdk/assemblyai`:

```ts
import { assemblyai } from '@ai-sdk/assemblyai';
```

If you need a customized setup, you can import `createAssemblyAI` from `@ai-sdk/assemblyai` and create a provider instance with your settings:

```ts
import { createAssemblyAI } from '@ai-sdk/assemblyai';

const assemblyai = createAssemblyAI({
  // custom settings, e.g.
  fetch: customFetch,
});
```

You can use the following optional settings to customize the AssemblyAI provider instance:

- **apiKey** _string | PromiseLike&lt;string&gt; | (() =&gt; string | PromiseLike&lt;string&gt;)_

  Pass a synchronous or asynchronous callback to resolve the key before each
  request. The callback is responsible for caching and refreshing credentials.

  API key that is being sent using the `Authorization` header.
  It defaults to the `ASSEMBLYAI_API_KEY` environment variable.

- **headers** _Record&lt;string,string&gt;_

  Custom headers to include in the requests.

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  Custom [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) implementation.
  Defaults to the global `fetch` function.
  You can use it as a middleware to intercept requests,
  or to provide a custom fetch implementation for e.g. testing.

- **webSocket** _WebSocketConstructor_

  Custom WebSocket implementation for streaming transcription, such as the
  `ws` package. AssemblyAI authenticates the streaming WebSocket with an
  `Authorization` header, which the native WebSocket in browsers, Node.js,
  Deno, and Bun cannot send.

## Transcription Models

You can create models that call the [AssemblyAI transcription API](https://www.assemblyai.com/docs/getting-started/transcribe-an-audio-file/typescript)
using the `.transcription()` factory method.

The first argument is the model id, e.g. `assemblyai-stt-3-7`.

```ts
const model = assemblyai.transcription('assemblyai-stt-3-7');
```

`assemblyai-stt-3-7` is AssemblyAI's latest flagship model for pre-recorded
audio. `universal-2` is fully supported and remains available for languages
`assemblyai-stt-3-7` does not support; using it emits an informational warning
(not a deprecation) suggesting `assemblyai-stt-3-7`.

AssemblyAI has deprecated `universal-3-5-pro`. It still works, but using it emits
a deprecation warning — prefer `assemblyai-stt-3-7`. The provider no longer lists
`universal-3-pro`, which AssemblyAI has deprecated and no longer includes in its
accepted models.

AssemblyAI no longer accepts the `best`, `slam-1`, and `nano` models: requests
for them fail with an AssemblyAI error that lists the accepted models. Models are
sent using the
[`speech_models`](https://www.assemblyai.com/docs/pre-recorded-audio/select-the-speech-model)
request parameter.

You can also pass additional provider-specific options using the `providerOptions` argument. For example, supplying the `contentSafety` option will enable content safety filtering.

```ts highlight="7"
import { transcribe } from 'ai';
import { assemblyai } from '@ai-sdk/assemblyai';
import { type AssemblyAITranscriptionModelOptions } from '@ai-sdk/assemblyai';
import { readFile } from 'fs/promises';

const result = await transcribe({
  model: assemblyai.transcription('assemblyai-stt-3-7'),
  audio: await readFile('audio.mp3'),
  providerOptions: {
    assemblyai: {
      contentSafety: true,
    } satisfies AssemblyAITranscriptionModelOptions,
  },
});
```

The following provider options are available:

- **audioEndAt** _number_

  End time of the audio in milliseconds.
  Optional.

- **audioStartFrom** _number_

  Start time of the audio in milliseconds.
  Optional.

- **autoChapters** _boolean_

  Whether to automatically generate chapters for the transcription.
  Optional.

- **autoHighlights** _boolean_

  Whether to automatically generate highlights for the transcription.
  Optional.

- **boostParam** _enum_

  Boost parameter for `wordBoost`.
  Allowed values: `'low'`, `'default'`, `'high'`.
  **Deprecated** — only applies to the deprecated `wordBoost`; use `keytermsPrompt` instead.
  Optional.

- **contentSafety** _boolean_

  Whether to enable content safety filtering.
  Optional.

- **contentSafetyConfidence** _number_

  Confidence threshold for content safety filtering (25-100).
  Optional.

- **customSpelling** _array of objects_

  Custom spelling rules for the transcription.
  Each object has `from` (array of strings) and `to` (string) properties.
  Optional.

- **disfluencies** _boolean_

  Whether to include disfluencies (um, uh, etc.) in the transcription.
  Optional.

- **domain** _string_

  Enable a domain-specific model for specialized terminology.
  Currently supports `'medical-v1'` (Medical Mode).
  Optional.

- **entityDetection** _boolean_

  Whether to detect entities in the transcription.
  Optional.

- **filterProfanity** _boolean_

  Whether to filter profanity in the transcription.
  Optional.

- **formatText** _boolean_

  Whether to format the text in the transcription.
  Optional.

- **iabCategories** _boolean_

  Whether to include IAB categories in the transcription.
  Optional.

- **keytermsPrompt** _array of strings_

  Domain-specific keyterms to boost recognition for (max 6 words per phrase).
  Replaces `wordBoost` for newer models — supported by `assemblyai-stt-3-7` and
  `universal-3-5-pro` (and `universal-2` when enabled).
  Optional.

- **languageCode** _string_

  Language code for the audio.
  Supports numerous ISO-639-1 and ISO-639-3 language codes.
  Optional.

- **languageConfidenceThreshold** _number_

  Confidence threshold for language detection.
  Optional.

- **languageDetection** _boolean_

  Whether to enable language detection.
  Optional.

- **languageDetectionOptions** _object_

  Options for automatic language detection: `expectedLanguages` (array of
  strings), `fallbackLanguage` (string), `codeSwitching` (boolean),
  `codeSwitchingConfidenceThreshold` (number, 0-1).
  Optional.

- **multichannel** _boolean_

  Whether to process multiple audio channels separately.
  Optional.

- **prompt** _string_

  Natural-language context (up to 1,500 words) to steer the model.
  Only supported by `assemblyai-stt-3-7` and `universal-3-5-pro`.
  Optional.

- **punctuate** _boolean_

  Whether to add punctuation to the transcription.
  Optional.

- **redactPii** _boolean_

  Whether to redact personally identifiable information.
  Optional.

- **redactPiiAudio** _boolean_

  Whether to redact PII in the audio file.
  Optional.

- **redactPiiAudioOptions** _object_

  Options for PII-redacted audio: `returnRedactedNoSpeechAudio` (boolean),
  `overrideAudioRedactionMethod` (`'silence'`). Requires `redactPiiAudio`.
  Optional.

- **redactPiiAudioQuality** _enum_

  Quality of the redacted audio file.
  Allowed values: `'mp3'`, `'wav'`.
  Optional.

- **redactPiiPolicies** _array of enums_

  Policies for PII redaction, specifying which types of information to redact.
  Supports numerous types like `'person_name'`, `'phone_number'`, etc.
  Optional.

- **redactPiiReturnUnredacted** _boolean_

  Return the original unredacted transcript alongside the redacted one.
  Requires `redactPii`.
  Optional.

- **redactPiiSub** _enum_

  Substitution method for redacted PII.
  Allowed values: `'entity_name'`, `'hash'`.
  Optional.

- **redactStaticEntities** _object_

  Map of user-defined labels to exact terms to redact, e.g.
  `{ INTERNAL_TOOL: ['Bearclaw'] }`. Applied on top of standard PII redaction.
  Requires `redactPii`.
  Optional.

- **removeAudioTags** _enum_

  Remove inline annotations from rich transcripts.
  Allowed values: `'all'` (all annotations), `'speaker'` (speaker cues only).
  AssemblyAI-STT-3.7 and Universal-3 Pro models.
  Optional.

- **sentimentAnalysis** _boolean_

  Whether to perform sentiment analysis on the transcription.
  Optional.

- **speakerLabels** _boolean_

  Whether to label different speakers in the transcription.
  Optional.

- **speakerOptions** _object_

  Options for speaker diarization: `minSpeakersExpected` (number),
  `maxSpeakersExpected` (number).
  Optional.

- **speakersExpected** _number_

  Expected number of speakers in the audio.
  Optional.

- **speechThreshold** _number_

  Threshold for speech detection (0-1).
  Optional.

- **summarization** _boolean_

  Whether to generate a summary of the transcription.
  Optional.

- **summaryModel** _enum_

  Model to use for summarization.
  Allowed values: `'informative'`, `'conversational'`, `'catchy'`.
  Optional.

- **summaryType** _enum_

  Type of summary to generate.
  Allowed values: `'bullets'`, `'bullets_verbose'`, `'gist'`, `'headline'`, `'paragraph'`.
  Optional.

- **temperature** _number_

  Sampling temperature (0-1) controlling randomness.
  AssemblyAI-STT-3.7 and Universal-3 Pro models.
  Optional.

- **webhookAuthHeaderName** _string_

  Name of the authentication header for webhook requests.
  Optional.

- **webhookAuthHeaderValue** _string_

  Value of the authentication header for webhook requests.
  Optional.

- **webhookUrl** _string_

  URL to send webhook notifications to.
  Optional.

- **wordBoost** _array of strings_

  List of words to boost in the transcription.
  **Deprecated** — rejected by `assemblyai-stt-3-7` and `universal-3-5-pro`
  (works only on `universal-2`); use `keytermsPrompt` instead.
  Optional.

### Speaker diarization and audio-intelligence results

The AI SDK's `transcribe` result exposes `text`, `segments`, `language`, and
`durationInSeconds`. AssemblyAI's richer results — speaker diarization and
audio-intelligence features — don't fit that shape, so they are surfaced in two
places:

- **`providerMetadata.assemblyai`** — structured results for the features you
  enabled: `utterances` (speaker-diarized segments, when `speakerLabels` is set),
  `entities`, `sentimentAnalysisResults`, `contentSafetyLabels`,
  `iabCategoriesResult`, and `autoHighlightsResult`.
- **`response.body`** — the complete, raw AssemblyAI transcript response, so any
  field not surfaced above (e.g. `chapters`, word-level `speaker` labels) is
  still available.

Note: timings inside `providerMetadata` and `response.body` (e.g.
`utterances[].start`) are in **milliseconds**, matching the AssemblyAI API —
whereas the top-level `segments` use **seconds**.

```ts
import { transcribe } from 'ai';
import { assemblyai } from '@ai-sdk/assemblyai';
import { readFile } from 'fs/promises';

const result = await transcribe({
  model: assemblyai.transcription('assemblyai-stt-3-7'),
  audio: await readFile('audio.mp3'),
  providerOptions: {
    assemblyai: {
      speakerLabels: true,
      entityDetection: true,
    },
  },
});

const { utterances, entities } = result.providerMetadata?.assemblyai ?? {};
// utterances: [{ speaker: 'A', text: '…', start, end, … }, …]  (start/end in ms)
```

The following AssemblyAI features are **deprecated** by the API and not surfaced
in `providerMetadata` (their output remains on the raw `response.body` if
enabled): Summarization, Auto Chapters, and Custom Topics. Note also that some
features are language-gated (e.g. sentiment analysis is English-centric); see
AssemblyAI's documentation for per-language availability.

## Streaming Transcription Models

<Note type="warning">Streaming transcription is an experimental feature.</Note>

`assemblyai-stt-3-7-realtime`, `assemblyai-stt-3-7-realtime-agent`, and
`universal-3-6-pro` support live transcription through
`experimental_streamTranscribe`. They accept 16-bit PCM (`audio/pcm`, default
16 kHz) or mu-law (`audio/pcmu`, default 8 kHz) audio at integer sample rates
from 8000 to 96000 Hz.

```ts
import {
  createAssemblyAI,
  type AssemblyAIProviderSettings,
} from '@ai-sdk/assemblyai';
import { experimental_streamTranscribe as streamTranscribe } from 'ai';
import { WebSocket } from 'ws';

const assemblyai = createAssemblyAI({
  webSocket: WebSocket as unknown as AssemblyAIProviderSettings['webSocket'],
});

const result = streamTranscribe({
  model: assemblyai.transcription('assemblyai-stt-3-7-realtime'),
  audio,
  inputAudioFormat: { type: 'audio/pcm', rate: 16000 },
  providerOptions: {
    assemblyai: {
      streaming: {
        keytermsPrompt: ['AI SDK'],
        languageDetection: true,
      },
    },
  },
});

for await (const part of result.fullStream) {
  if (part.type === 'transcript-partial') {
    console.log('partial:', part.text);
  }

  if (part.type === 'transcript-final') {
    console.log('final:', part.text);
  }
}
```

The AssemblyAI streaming endpoint authenticates with a WebSocket header. Use a
header-capable WebSocket implementation, such as `ws`, in runtimes whose native
WebSocket constructor cannot send headers.

AssemblyAI requires each audio message to carry 20 to 1000 ms of audio and
recommends 50 to 100 ms, so the provider regroups incoming chunks into messages
of 20 to 100 ms and pads a final chunk shorter than 20 ms with silence. When the
audio stream ends, the provider ends the session with a `Terminate` message,
and the finish event reports the exact duration of the audio sent as
`durationInSeconds`, and AssemblyAI's `audio_duration_seconds` and
`session_duration_seconds` (whole seconds) as `usage`. Cancelling the stream or
aborting the request also sends `Terminate` before closing the socket.

Live audio is paced by the microphone. When streaming a file, pace it close to
real time: AssemblyAI accepts audio faster than real time but processes it at
about 1.25 times real time, and closes the session with error `3007` once more
than five minutes of audio is buffered ahead of processing.

With `inactivityTimeout` set, AssemblyAI ends the session when no audio arrives
for that many seconds. The stream then finishes normally with the turns
finalized so far; a turn still in progress has no final transcript and is not
included, and `usage` is omitted because AssemblyAI does not report it.

The `streaming` provider options mirror AssemblyAI's streaming connection
parameters: `agentContext`, `domain`, `filterProfanity`, `inactivityTimeout`,
`includePartialTurns`, `interruptionDelay`, `keytermsPrompt`, `languageCodes`,
`languageDetection`, `maxSpeakers`, `maxTurnSilence`, `minTurnSilence`, `mode`,
`previousContextNTurns`, `prompt`, `redactPii`, `redactPiiPolicies`,
`redactPiiSub`, `speakerLabels`, `vadThreshold`, `voiceFocus`, and
`voiceFocusThreshold`. The other `assemblyai` provider options apply to
pre-recorded transcription only. When `speakerLabels` is enabled, each final
transcript part carries the turn's speaker in
`providerMetadata.assemblyai.speakerLabel`.

See [Transcription](/docs/ai-sdk-core/transcription) for more information about
streaming transcription.

## Speech Models

You can create models that call the [AssemblyAI text-to-speech API](https://www.assemblyai.com/docs/tts/api-reference/http-api/create-speech)
using the `.speech()` factory method.

The first argument is the model id, e.g. `assemblyai-tts-1`.

```ts
import { generateSpeech } from 'ai';
import { assemblyai } from '@ai-sdk/assemblyai';

const result = await generateSpeech({
  model: assemblyai.speech('assemblyai-tts-1'),
  text: 'Hello, world!',
  voice: 'aai-kyla',
  language: 'en',
});
```

The `voice` option takes an [AssemblyAI voice](https://www.assemblyai.com/docs/tts/voices)
slug (e.g. `aai-kyla`), a voice ID, or the ID or slug of one of your cloned
voices. Without a voice, AssemblyAI uses the default voice of the language.

The `language` option takes an ISO 639-1 code for one of the supported
languages: `en`, `es`, `de`, `it`, `pt`, or `fr`. Without a language,
the voice speaks its own language.

The `outputFormat` option supports `'mp3'` (default), `'wav'`, `'pcm'`
(raw 16-bit PCM), `'mulaw'`, and `'alaw'` (raw 8 kHz G.711).
Text-to-speech requests are buffered, so `generateSpeech` returns the complete
audio once it is synthesized.

`speed` (other than `1`) and `instructions` are not supported and are ignored
with a warning.

You can also pass additional provider-specific options using the `providerOptions` argument:

```ts highlight="7-12"
import { generateSpeech } from 'ai';
import {
  assemblyai,
  type AssemblyAISpeechModelOptions,
} from '@ai-sdk/assemblyai';

const result = await generateSpeech({
  model: assemblyai.speech('assemblyai-tts-1'),
  text: 'Your appointment is confirmed.',
  providerOptions: {
    assemblyai: {
      encoding: 'pcm_s16le',
      container: 'wav',
      sampleRate: 16000,
    } satisfies AssemblyAISpeechModelOptions,
  },
});
```

The following provider options are available:

- **encoding** _enum_

  Audio encoding of the output. Overrides the encoding derived from `outputFormat`.
  Allowed values: `'pcm_s16le'`, `'pcm_mulaw'`, `'pcm_alaw'`, `'mp3'`.
  Optional.

- **container** _enum_

  `'raw'` returns the encoded samples alone; `'wav'` wraps them in a WAV file.
  Requires a `pcm_*` encoding.
  Optional.

- **sampleRate** _number_

  Sample rate of the output audio in Hz.
  Allowed values: `8000`, `16000`, `22050`, `24000`, `44100`, `48000`.
  Optional.

- **bitRate** _number_

  MP3 bit rate in bits per second. MP3 output only.
  Allowed values: `32000`, `48000`, `64000`, `96000`, `128000`.
  Optional.

`providerMetadata.assemblyai.billedCharacters` reports the characters AssemblyAI
billed for the request (the model also reports them as `characters` usage to
telemetry integrations). `providerMetadata.assemblyai` also includes the
`requestId`, `model`, `voiceId`, `language`, `encoding`, `sampleRate`, and
`audioDurationMs` reported by the API.
