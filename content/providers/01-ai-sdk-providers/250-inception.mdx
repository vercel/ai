# Inception Provider

The [Inception](https://inceptionlabs.ai) provider supports Mercury language models through Inception's [chat completions API](https://docs.inceptionlabs.ai/api-reference/chat/create-a-chat-completion)
and Mercury Decide through the [Decisions API](https://docs.inceptionlabs.ai/api-reference/decisions/create-a-decision).

## Setup

The Inception provider is available in the `@ai-sdk/inception` module:

<InstallPackages packages="@ai-sdk/inception" />

Set the `INCEPTION_API_KEY` environment variable to your API key from the
[Inception platform](https://platform.inceptionlabs.ai).

## Provider Instance

Import the default provider instance:

```ts
import { inception } from '@ai-sdk/inception';
```

For custom configuration, use `createInception`:

```ts
import { createInception } from '@ai-sdk/inception';

const inception = createInception({
  apiKey: 'your-api-key',
});
```

The following settings are available:

- **apiKey** _string | PromiseLike&lt;string&gt; | (() =&gt; string | PromiseLike&lt;string&gt;)_

  API key sent in the `Authorization` header. Defaults to `INCEPTION_API_KEY`.
  A function is resolved before every request to support rotating credentials.

- **baseURL** _string_

  URL prefix for API calls. Defaults to `https://api.inceptionlabs.ai/v1`.

- **headers** _Record&lt;string, string&gt;_

  Additional HTTP headers to include in requests.

- **fetch** _FetchFunction_

  Custom fetch implementation.

## Language Models

Create a chat model with `inception(modelId)`. You can also use
`inception.chat(modelId)` or `inception.languageModel(modelId)`.

```ts
import { inception } from '@ai-sdk/inception';
import { generateText } from 'ai';

const { text } = await generateText({
  model: inception('mercury-3'),
  prompt: 'Explain diffusion language models in one paragraph.',
});
```

### Reasoning Effort

Use the top-level `reasoning` option to control how much the model deliberates
before answering. When omitted, the API uses the model's default.

```ts
import { inception } from '@ai-sdk/inception';
import { generateText } from 'ai';

const { text } = await generateText({
  model: inception('mercury-3'),
  reasoning: 'high',
  prompt: 'Solve this step by step: 3x + 7 = 22.',
});
```

`none` and `minimal` map to `instant`; `low`, `medium`, and `high` map directly;
`xhigh` and `max` map to `high`.

To select an Inception effort directly, set
`providerOptions.inception.reasoningEffort` to `instant`, `low`, `medium`, or
`high`. This provider-specific option takes precedence over `reasoning`.

### Streaming

```ts
import { inception } from '@ai-sdk/inception';
import { streamText } from 'ai';

const result = streamText({
  model: inception('mercury-3'),
  prompt: 'Write a short story about a robot gardener.',
});

for await (const text of result.textStream) {
  process.stdout.write(text);
}
```

Streaming uses standard server-sent events and includes token usage.

### Structured Outputs

```ts
import { inception } from '@ai-sdk/inception';
import { generateText, Output } from 'ai';
import { z } from 'zod';

const { output } = await generateText({
  model: inception('mercury-3'),
  output: Output.object({
    schema: z.object({
      sentiment: z.enum(['positive', 'negative', 'neutral']),
      confidence: z.number().min(0).max(1),
    }),
  }),
  prompt: 'Analyze the sentiment: I love this feature!',
});
```

JSON schemas are sent using `response_format.type: 'json_schema'` with strict
validation enabled by default. Structured output also works with `streamText`.

### Tool Calling

Mercury supports function tools, parallel tool calls, and streaming tool calls.
Use the standard AI SDK `tools` and `toolChoice` settings. Tool results are sent
back as tool messages for multi-step generation.

### Provider Options

The following `InceptionLanguageModelChatOptions` can be passed under
`providerOptions.inception`:

- **reasoningEffort** _'instant' | 'low' | 'medium' | 'high'_

  How much the model deliberates before responding.

- **strictJsonSchema** _boolean_

  Whether to use strict JSON schema validation. Defaults to `true`.

- **realtime** _boolean_

  Optimize for workloads that require lower time to first token.

`maxOutputTokens` maps to `max_completion_tokens`, which includes reasoning
tokens. `temperature` and `stopSequences` are supported. The API accepts
temperatures from 0.5 to 1; values outside this range are reset by the API to the
model's default. Unsupported `topP`, `topK`, `frequencyPenalty`, `presencePenalty`,
and `seed` settings are omitted with warnings.

## Decision Models

Use `inception.decisionModel('mercury-decide')` with the experimental `decide`
function to evaluate named questions against shared text, JSON, or image state.
All questions are sent together to `POST /v1/decisions`.

```ts
import { inception } from '@ai-sdk/inception';
import { experimental_decide as decide } from 'ai';

const result = await decide({
  model: inception.decisionModel('mercury-decide'),
  state: { message: 'Please refund the duplicate charge on my account.' },
  questions: {
    billing: {
      type: 'boolean',
      instructions: 'Is this request about billing?',
    },
    team: {
      type: 'choice',
      criteria: {
        billing: 'Payments, charges, and refunds',
        support: 'Technical support and other requests',
      },
    },
    urgency: {
      type: 'score',
      instructions: 'How urgent is this request?',
      criteria: [
        'Can wait',
        'Needs attention soon',
        'Needs immediate attention',
      ],
    },
  },
});

console.log(result.answers.billing.probability);
console.log(result.answers.team.choice);
console.log(result.answers.urgency.score);
```

### Question Types

| AI SDK type | Inception type | Result                                                                                                  |
| ----------- | -------------- | ------------------------------------------------------------------------------------------------------- |
| `boolean`   | `noul`         | `probability`: the probability of a positive answer, between 0 and 1                                    |
| `choice`    | `choice`       | `choice`: the highest-probability option, with `probabilities` for all options                          |
| `score`     | `score`        | `score`: the probability-weighted mean of zero-based level indices, with `probabilities` for all levels |

Choice questions require 1–255 named criteria; descriptions may be `null`.
Score questions require 1–10 non-null criteria and can return fractional scores.
Instructions and criterion descriptions can be strings, JSON objects, or arrays.
Instructions may be omitted or `null` when criteria define the judgment.
Boolean questions can supply `criteria.true` and `criteria.false` descriptions.

`providerMetadata.inception.confidence` contains confidence values for choice
and score answers, keyed by question name. `providerMetadata.inception.legend`
contains score level descriptions, keyed by question name and level index.
The exported `InceptionDecisionProviderMetadata` type describes these fields.
Both input and output token counts are preserved in `usage`.

### Image State

Pass image bytes or a base64 string in a `file` state part:

```ts
import { inception } from '@ai-sdk/inception';
import { experimental_decide as decide } from 'ai';
import { readFileSync } from 'node:fs';

const result = await decide({
  model: inception.decisionModel('mercury-decide'),
  state: [
    { type: 'text', text: 'Inspect this screenshot.' },
    {
      type: 'file',
      mediaType: 'image/png',
      data: readFileSync('./screenshot.png'),
    },
  ],
  questions: {
    errorShown: {
      type: 'boolean',
      instructions: 'Does the page show a payment error?',
    },
  },
});
```

The provider converts file parts to Inception's base64 `image_url` format.
PNG, JPEG, WebP, and GIF are supported. The API permits up to 16 images,
10 MiB per image, with a default 20 MiB limit for the complete JSON request.
Images can appear in state or instructions, but not in criteria. Native
`image_url` parts inside JSON state or instructions must use base64 data URLs;
Inception does not fetch remote image URLs.

### Decision Model Capabilities

| Model            | Boolean   | Choice    | Score     | Box       | Image Input | Reasoning | Max Output Tokens |
| ---------------- | --------- | --------- | --------- | --------- | ----------- | --------- | ----------------- |
| `mercury-decide` | <Check /> | <Check /> | <Check /> | <Cross /> | <Check />   | <Cross /> | <Cross />         |

{/* model-capabilities:inception-decision:end */}

Mercury Decide does not support streaming, tool calling, box questions, or
provider-specific decision options. `reasoning` and `maxOutputTokens` are
omitted with warnings. The AI SDK decision interface currently exposes boolean,
choice, and score questions for this provider; Inception's `extract` question
type is not exposed.

See Inception's [Decisions guide](https://docs.inceptionlabs.ai/capabilities/decisions)
and [API reference](https://docs.inceptionlabs.ai/api-reference/decisions/create-a-decision)
for the native request and response formats.
