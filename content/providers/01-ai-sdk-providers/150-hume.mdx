# Hume Provider

The [Hume](https://hume.ai/) provider is available in the `@ai-sdk/hume` package.
Hume retired its text-to-speech (TTS) API on November 13, 2026, so the package no longer includes a speech model.

## Setup

Install `ai` and `@ai-sdk/hume`:

<InstallPackages packages="ai @ai-sdk/hume" />

## Provider Instance

You can import the default provider instance `hume` from `@ai-sdk/hume`:

```ts
import { hume } from '@ai-sdk/hume';
```
