# Interfaze Provider

The [Interfaze](https://interfaze.ai) provider offers access to Interfaze's OpenAI-compatible LLM API, which adds semantic response caching, a reasoning trace, and internal-tool precontext (OCR, web search, scraping, speech-to-text, forecasting) on top of a standard chat completions interface.

API keys can be obtained from the [Interfaze Platform](https://interfaze.ai).

## Setup

The Interfaze provider is available via the `@ai-sdk/interfaze` module. You can install it with:

<InstallPackages packages="@ai-sdk/interfaze" />

## Provider Instance

You can import the default provider instance `interfaze` from `@ai-sdk/interfaze`:

```ts
import { interfaze } from '@ai-sdk/interfaze';
```

For custom configuration, you can import `createInterfaze` and create a provider instance with your settings:

```ts
import { createInterfaze } from '@ai-sdk/interfaze';

const interfaze = createInterfaze({
  apiKey: process.env.INTERFAZE_API_KEY ?? '',
});
```

You can use the following optional settings to customize the Interfaze provider instance:

- **baseURL** _string_

  Use a different URL prefix for API calls.
  The default prefix is `https://api.interfaze.ai/v1`.

- **apiKey** _string_

  API key that is being sent using the `Authorization` header. It defaults to
  the `INTERFAZE_API_KEY` environment variable.

- **headers** _Record&lt;string,string&gt;_

  Custom headers to include in the requests.

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  Custom [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) implementation.

## Language Models

You can create language models using a provider instance:

```ts
import { interfaze } from '@ai-sdk/interfaze';
import { generateText } from 'ai';

const { text } = await generateText({
  model: interfaze('interfaze-beta'),
  prompt: 'Write a vegetarian lasagna recipe for 4 people.',
});
```

You can also use the `.chat()` or `.languageModel()` factory methods:

```ts
const model = interfaze.chat('interfaze-beta');
// or
const model = interfaze.languageModel('interfaze-beta');
```

Interfaze language models can be used in the `streamText` function
(see [AI SDK Core](/docs/ai-sdk-core)).

### Provider Options

The following optional provider option is available for Interfaze models via `providerOptions.interfaze`:

- **precontext** _unknown[]_

  Previously-computed internal-task results (OCR / web search / scrape / speech-to-text / forecast / …) to inject into this request instead of having Interfaze recompute them. Sent as a top-level `precontext` field on the request body.

```ts
import {
  interfaze,
  type InterfazeLanguageModelChatOptions,
} from '@ai-sdk/interfaze';
import { generateText } from 'ai';

const { text } = await generateText({
  model: interfaze('interfaze-beta'),
  prompt: 'Summarize the search results.',
  providerOptions: {
    interfaze: {
      precontext: [
        { name: 'web_search', result: { query: 'ai sdk', hits: 12 } },
      ],
    } satisfies InterfazeLanguageModelChatOptions,
  },
});
```

### Video Input

Interfaze accepts video files as a `file` part. Pass video bytes or a URL the same way you would an image or PDF:

```ts
import { interfaze } from '@ai-sdk/interfaze';
import { generateText } from 'ai';
import { readFile } from 'node:fs/promises';

const { text } = await generateText({
  model: interfaze('interfaze-beta'),
  messages: [
    {
      role: 'user',
      content: [
        { type: 'text', text: 'Summarize this clip.' },
        {
          type: 'file',
          data: await readFile('./clip.mp4'),
          mediaType: 'video/mp4',
        },
      ],
    },
  ],
});
```

## Interfaze-Specific Metadata

Interfaze adds three fields on top of the standard chat completion response:

- `vcache` _boolean_ — whether the response was served from Interfaze's semantic cache.
- `reasoning` _string_ — the model's reasoning trace, present when `reasoning_effort` produced one.
- `precontext` _unknown[]_ — raw results from internal tasks Interfaze ran (OCR / web search / scrape / speech-to-text / forecast / …).

These are exposed under `providerMetadata.interfaze` for both `generateText` and `streamText`:

```ts
import { interfaze } from '@ai-sdk/interfaze';
import { generateText } from 'ai';

const result = await generateText({
  model: interfaze('interfaze-beta'),
  prompt: 'What is the weather in San Francisco?',
});

console.log(result.providerMetadata?.interfaze?.vcache); // boolean
console.log(result.providerMetadata?.interfaze?.reasoning); // string | undefined
console.log(result.providerMetadata?.interfaze?.precontext); // unknown[] | undefined
```

<Note>
  Interfaze embeds its reasoning trace and internal-task results as inline
  `<think>`/`<precontext>` tags in streamed content, rather than as separate
  streaming events. The AI SDK Interfaze provider strips these tags from the
  visible text as it streams and only finishes extracting `reasoning` /
  `precontext` into `providerMetadata.interfaze` once the stream completes —
  they are available on the `finish-step` stream part, not incrementally.
</Note>

```ts
import { interfaze } from '@ai-sdk/interfaze';
import { streamText } from 'ai';

const result = streamText({
  model: interfaze('interfaze-beta'),
  prompt: 'What is the weather in San Francisco?',
});

for await (const part of result.stream) {
  if (part.type === 'text-delta') {
    process.stdout.write(part.text);
  } else if (part.type === 'finish-step') {
    console.log(part.providerMetadata?.interfaze?.reasoning);
  }
}
```
