# Powerspring Provider

[Powerspring](https://powerspring.eu/) serves popular open-weight models, including gpt-oss, DeepSeek, GLM, Qwen and Gemma, through an OpenAI-compatible API. Every request runs on EU infrastructure owned by EU companies, and Powerspring does not store prompts or outputs. You can use its Chat Completions endpoint with the AI SDK through the `@ai-sdk/openai-compatible` module.

## Setup

Install the OpenAI Compatible provider:

<InstallPackages packages="@ai-sdk/openai-compatible" />

Create an API key in the [Powerspring console](https://app.powerspring.eu/signup) and set it as a server-side environment variable:

```bash
export POWERSPRING_API_KEY=your-api-key
```

## Provider Instance

Create a Powerspring provider instance with `createOpenAICompatible`:

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';

const powerspring = createOpenAICompatible({
  name: 'powerspring',
  apiKey: process.env.POWERSPRING_API_KEY,
  baseURL: 'https://api.powerspring.eu/v1',
  includeUsage: true, // Include usage information in streaming responses
});
```

The `apiKey` setting sends your key as a Bearer token in the `Authorization` header.

## Language Models

Create a language model by passing a Powerspring model ID to the provider instance:

```ts
const model = powerspring('gpt-oss-120b');
```

### Generate Text

Use `generateText` to generate text with the model:

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';
import { generateText } from 'ai';

const powerspring = createOpenAICompatible({
  name: 'powerspring',
  apiKey: process.env.POWERSPRING_API_KEY,
  baseURL: 'https://api.powerspring.eu/v1',
  includeUsage: true,
});

const { text } = await generateText({
  model: powerspring('gpt-oss-120b'),
  prompt: 'Summarise this clause in two sentences.',
});

console.log(text);
```

### Stream Text

Use `streamText` to stream text as it is generated:

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';
import { streamText } from 'ai';

const powerspring = createOpenAICompatible({
  name: 'powerspring',
  apiKey: process.env.POWERSPRING_API_KEY,
  baseURL: 'https://api.powerspring.eu/v1',
  includeUsage: true,
});

const result = streamText({
  model: powerspring('deepseek-v4.1-flash'),
  prompt: 'Count from 1 to 5, separated by spaces.',
});

for await (const textPart of result.textStream) {
  process.stdout.write(textPart);
}
```

## Supported Models and Capabilities

This integration uses Powerspring's OpenAI-compatible Chat Completions endpoint for text generation and streaming, with text input. Tool calling and JSON mode depend on the selected model.

The [`GET /v1/models`](https://api.powerspring.eu/v1/models) endpoint lists the current model IDs, context lengths, capabilities and prices. The same list, with independent benchmark scores, is on the [models page](https://powerspring.eu/models).
