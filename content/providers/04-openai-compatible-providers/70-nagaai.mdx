# NagaAI Provider

[NagaAI](https://naga.ac/) is an API gateway that serves models from multiple AI labs through an OpenAI-compatible API. It accepts the Responses API and Chat Completions on the same base URL. With the AI SDK, use the `@ai-sdk/openai` module for the Responses API, or `@ai-sdk/openai-compatible` for Chat Completions.

## Setup

Install the OpenAI provider:

<InstallPackages packages="@ai-sdk/openai" />

Create a NagaAI API key in the [dashboard](https://naga.ac/dashboard/api-keys) and set it as a server-side environment variable:

```bash
export NAGA_API_KEY=your-api-key
```

## Provider Instance

Create a NagaAI provider instance with `createOpenAI`:

```ts
import { createOpenAI } from '@ai-sdk/openai';

const naga = createOpenAI({
  apiKey: process.env.NAGA_API_KEY,
  baseURL: 'https://api.naga.ac/v1',
});
```

The `apiKey` setting sends your key as a Bearer token in the `Authorization` header.

## Language Models

Create a language model with `naga.responses()`, which selects the Responses API explicitly. NagaAI model IDs carry the vendor prefix:

```ts
const model = naga.responses('anthropic/claude-sonnet-5.5');
```

NagaAI does not store responses. Set `store: false` in the OpenAI provider options on every call. Without it, the provider sends earlier turns as references to stored responses, and the second turn of a conversation fails with a `400` error.

### Generate Text

Use `generateText` to generate text with the model:

```ts
import { createOpenAI } from '@ai-sdk/openai';
import { generateText } from 'ai';

const naga = createOpenAI({
  apiKey: process.env.NAGA_API_KEY,
  baseURL: 'https://api.naga.ac/v1',
});

const { text } = await generateText({
  model: naga.responses('openai/gpt-6.1-sol'),
  prompt: 'Explain what an API gateway does in one sentence.',
  providerOptions: { openai: { store: false } },
});

console.log(text);
```

### Stream Text

Use `streamText` to stream text as it is generated:

```ts
import { createOpenAI } from '@ai-sdk/openai';
import { streamText } from 'ai';

const naga = createOpenAI({
  apiKey: process.env.NAGA_API_KEY,
  baseURL: 'https://api.naga.ac/v1',
});

const result = streamText({
  model: naga.responses('openai/gpt-6.1-sol'),
  prompt: 'Count from 1 to 5, separated by spaces.',
  providerOptions: { openai: { store: false } },
});

for await (const textPart of result.textStream) {
  process.stdout.write(textPart);
}
```

### Reasoning

Pass `reasoningEffort` in the OpenAI provider options. NagaAI accepts `none` to `max` and runs the nearest level the model supports. The provider recognizes reasoning models by OpenAI model IDs only, so set `forceReasoning: true` for NagaAI model IDs, otherwise `reasoningEffort` is dropped with a warning:

```ts
const { text } = await generateText({
  model: naga.responses('openai/gpt-6.1-sol'),
  prompt: 'Is 221 a prime number?',
  providerOptions: {
    openai: {
      store: false,
      forceReasoning: true,
      reasoningEffort: 'medium',
      reasoningSummary: 'detailed',
    },
  },
});
```

With `store: false`, the provider also requests `reasoning.encrypted_content`. To continue the conversation, pass the complete `response.messages` of the result into the next call, so the encrypted reasoning goes back with it.

### Chat Completions

To call Chat Completions instead, install the OpenAI Compatible provider:

<InstallPackages packages="@ai-sdk/openai-compatible" />

Then create a second provider instance with `createOpenAICompatible`:

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';
import { streamText } from 'ai';

const nagaChat = createOpenAICompatible({
  name: 'nagaai',
  apiKey: process.env.NAGA_API_KEY,
  baseURL: 'https://api.naga.ac/v1',
  includeUsage: true,
});

const result = streamText({
  model: nagaChat('openai/gpt-6.1-sol'),
  prompt: 'Count from 1 to 5, separated by spaces.',
});

for await (const textPart of result.textStream) {
  process.stdout.write(textPart);
}

console.log(await result.usage);
```

This provider sends requests to `/chat/completions`. `includeUsage: true` requests token usage in streaming responses. Its provider options use the `nagaai` key, matching the configured `name`, for example `providerOptions: { nagaai: { reasoningEffort: 'high' } }`.

## Supported Models and Capabilities

Support for tools, vision, and reasoning depends on the selected model. The public [`GET /v1/models`](https://api.naga.ac/v1/models) endpoint lists current model IDs with their context windows, supported parameters, and pricing; no API key is needed.
