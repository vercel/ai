# Zurelay Provider

[Zurelay](https://zurelay.com/) is an API gateway for models from Anthropic, OpenAI, Google, xAI, DeepSeek, Alibaba and other labs, priced below each lab's list price. It exposes an OpenAI-compatible API, so you can use its Chat Completions and Images endpoints with the AI SDK through the `@ai-sdk/openai-compatible` module.

## Setup

Install the OpenAI Compatible provider:

<InstallPackages packages="@ai-sdk/openai-compatible" />

Create a Zurelay API key in the [Zurelay dashboard](https://zurelay.com/app/keys) and set it as a server-side environment variable:

```bash
export ZURELAY_API_KEY=your-api-key
```

## Provider Instance

Create a Zurelay provider instance with `createOpenAICompatible`:

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';

const zurelay = createOpenAICompatible({
  name: 'zurelay',
  apiKey: process.env.ZURELAY_API_KEY,
  baseURL: 'https://api.zurelay.com/v1',
  includeUsage: true,
});
```

The `apiKey` setting sends your key as a Bearer token in the `Authorization` header.

## Language Models

Create a language model by passing a Zurelay model ID to the provider instance:

```ts
const model = zurelay('claude-sonnet-5-5');
```

### Generate Text

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';
import { generateText } from 'ai';

const zurelay = createOpenAICompatible({
  name: 'zurelay',
  apiKey: process.env.ZURELAY_API_KEY,
  baseURL: 'https://api.zurelay.com/v1',
});

const { text } = await generateText({
  model: zurelay('gpt-6-sol'),
  prompt: 'Explain what an API gateway does in one sentence.',
});

console.log(text);
```

### Stream Text

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';
import { streamText } from 'ai';

const zurelay = createOpenAICompatible({
  name: 'zurelay',
  apiKey: process.env.ZURELAY_API_KEY,
  baseURL: 'https://api.zurelay.com/v1',
});

const result = streamText({
  model: zurelay('deepseek-v4.1-flash'),
  prompt: 'Count from 1 to 5, separated by spaces.',
});

for await (const textPart of result.textStream) {
  process.stdout.write(textPart);
}
```

### Reasoning

Reasoning models take an effort level through `providerOptions`. Each model accepts the levels its lab documents; the [models page](https://zurelay.com/docs/models) lists them.

```ts
const { text, reasoningText } = await generateText({
  model: zurelay('claude-opus-5-5'),
  prompt: 'How many weekdays are there in March 2027?',
  providerOptions: {
    zurelay: { reasoningEffort: 'high' },
  },
});
```

## Image Models

Create an image model with `.imageModel()` and use it with `generateImage`:

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';
import { generateImage } from 'ai';

const zurelay = createOpenAICompatible({
  name: 'zurelay',
  apiKey: process.env.ZURELAY_API_KEY,
  baseURL: 'https://api.zurelay.com/v1',
});

const { image } = await generateImage({
  model: zurelay.imageModel('gpt-image-2.5-flare'),
  prompt: 'A lighthouse on a cliff at dusk, watercolor',
  size: '1024x1024',
});
```

## Supported Models and Capabilities

Tool calling, structured output, image and PDF input, and streaming depend on the selected model. Use [`GET /v1/models`](https://zurelay.com/docs/models) to list current model IDs and what each one reads, or see the model catalog for prices.
