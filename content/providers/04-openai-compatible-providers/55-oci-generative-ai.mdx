# OCI Generative AI Provider

[OCI Generative AI](https://docs.oracle.com/en-us/iaas/Content/generative-ai/home.htm) is Oracle Cloud Infrastructure's managed inference service. It exposes an OpenAI-compatible API at `https://inference.generativeai.<region>.oci.oraclecloud.com/openai/v1`, so you can use it with the AI SDK through the `@ai-sdk/openai-compatible` module.

## Setup

The OCI Generative AI provider is available via the `@ai-sdk/openai-compatible` module as it is compatible with the OpenAI API. You can install it with:

<InstallPackages packages="@ai-sdk/openai-compatible" />

### OCI Setup

1. In the [OCI Console](https://cloud.oracle.com/), open the Generative AI service in a region that hosts it, such as US Midwest (Chicago), and create an **API key** in your compartment. Copy the key; it is shown only once.

   The key needs an IAM policy in place _before_ it is created, otherwise every request returns `401`:

   ```txt
   allow any-user to use generative-ai-family in compartment YOUR_COMPARTMENT where request.principal.type='generativeaiapikey'
   ```

2. Export the key:

   ```bash
   export OCI_GENAI_API_KEY=your-api-key
   ```

## Provider Instance

To use OCI Generative AI, you can create a custom provider instance with the `createOpenAICompatible` function from `@ai-sdk/openai-compatible`. Use the endpoint of the region your key belongs to:

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';

const oci = createOpenAICompatible({
  name: 'oci',
  baseURL:
    'https://inference.generativeai.us-chicago-1.oci.oraclecloud.com/openai/v1',
  apiKey: process.env.OCI_GENAI_API_KEY,
});
```

<Note>
  The API key is scoped to the compartment it was created in, so no compartment
  header is needed. Replace `us-chicago-1` with your region, for example
  `eu-frankfurt-1`.
</Note>

## Language Models

You can create OCI Generative AI models using a provider instance. The first argument is the model ID as listed in the OCI Generative AI [pretrained models catalog](https://docs.oracle.com/en-us/iaas/Content/generative-ai/pretrained-models.htm), e.g. `xai.grok-4.6`.

```ts
const model = oci('xai.grok-4.6');
```

The OpenAI-compatible endpoint serves the Meta Llama, xAI Grok, and OpenAI gpt-oss models to API keys, for example `meta.llama-3.3-70b-instruct`, `meta.llama-4-maverick-17b-128e-instruct-fp8`, `openai.gpt-oss-120b`, and `xai.grok-4.6`. Other models in the OCI catalog are only available through the native OCI API.

### Example

You can use OCI Generative AI language models to generate text with the `generateText` function:

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';
import { generateText } from 'ai';

const oci = createOpenAICompatible({
  name: 'oci',
  baseURL:
    'https://inference.generativeai.us-chicago-1.oci.oraclecloud.com/openai/v1',
  apiKey: process.env.OCI_GENAI_API_KEY,
});

const { text } = await generateText({
  model: oci('xai.grok-4.6'),
  prompt: 'Tell me about yourself in one sentence',
});

console.log(text);
```

OCI Generative AI language models are also able to generate text in a streaming fashion with the `streamText` function:

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';
import { streamText } from 'ai';

const oci = createOpenAICompatible({
  name: 'oci',
  baseURL:
    'https://inference.generativeai.us-chicago-1.oci.oraclecloud.com/openai/v1',
  apiKey: process.env.OCI_GENAI_API_KEY,
});

const result = streamText({
  model: oci('xai.grok-4.6'),
  prompt: 'Tell me about yourself in one sentence',
});

for await (const message of result.textStream) {
  console.log(message);
}
```

<Note>
  The Llama models on this endpoint reject tool calls when the request starts
  with a system message. Use the Grok or gpt-oss models for tool calling.
</Note>
