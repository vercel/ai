# OpenZoo Provider

[OpenZoo](https://openzoo.fun) provides pay-per-call access to a large catalog of
models through an OpenAI-compatible API. There is no account or signup: any API
key value is accepted, and usage is settled per request via the x402 protocol
(USDC on Solana or Base), by card, or automatically by a local gateway. You can
use it with the AI SDK through the `@ai-sdk/openai-compatible` module.

## Setup

The OpenZoo provider is available via the `@ai-sdk/openai-compatible` module as
it is compatible with the OpenAI API. You can install it with:

<InstallPackages packages="@ai-sdk/openai-compatible" />

## Provider Instance

To use OpenZoo, create a custom provider instance with the `createOpenAICompatible`
function from `@ai-sdk/openai-compatible`:

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';

const openzoo = createOpenAICompatible({
  name: 'openzoo',
  baseURL: 'https://api.openzoo.fun/v1',
  apiKey: process.env.OPENZOO_API_KEY ?? 'sk-openzoo',
});
```

<Note>
  OpenZoo does not require signup — any API key value is accepted (for example
  `sk-openzoo`). You can also run a local gateway with `npx openzoo` and set
  `baseURL: 'http://localhost:8402/v1'`; the gateway pays per call on your
  behalf.
</Note>

## Language Models

You can create OpenZoo models using the provider instance. The first argument is
a model ID from the [model catalog](https://api.openzoo.fun/v1/models), for
example `z-ai/glm-5.3-flash`:

```ts
const model = openzoo('z-ai/glm-5.3-flash');
```

### Example

You can use OpenZoo language models to generate text with the `generateText`
function:

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';
import { generateText } from 'ai';

const openzoo = createOpenAICompatible({
  name: 'openzoo',
  baseURL: 'https://api.openzoo.fun/v1',
  apiKey: 'sk-openzoo',
});

const { text } = await generateText({
  model: openzoo('z-ai/glm-5.3-flash'),
  prompt: 'Tell me about yourself in one sentence.',
});
```

OpenZoo language models can also be used with `streamText` (SSE streaming is
supported):

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';
import { streamText } from 'ai';

const openzoo = createOpenAICompatible({
  name: 'openzoo',
  baseURL: 'https://api.openzoo.fun/v1',
  apiKey: 'sk-openzoo',
});

const result = streamText({
  model: openzoo('z-ai/glm-5.3-flash'),
  prompt: 'Write a short haiku about micro-payments.',
});

for await (const textPart of result.textStream) {
  process.stdout.write(textPart);
}
```

The model list at
[`https://api.openzoo.fun/v1/models`](https://api.openzoo.fun/v1/models) is free
to fetch and includes per-model pricing (`prompt_price_per_1m` /
`completion_price_per_1m`) and context metadata.
