# Frequency Provider

[Frequency](https://scalefrequency.com) is a voice-first, low-latency inference provider based in India that serves models through an OpenAI-compatible API. Requests enter at an edge in Delhi and run on dedicated GPUs in India, keeping prompts and completions within the country. You can use its Chat Completions endpoint with the AI SDK through the `@ai-sdk/openai-compatible` module.

## Setup

The Frequency provider is available via the `@ai-sdk/openai-compatible` module as it is compatible with the OpenAI API. You can install it with:

<InstallPackages packages="@ai-sdk/openai-compatible" />

## Provider Instance

To use Frequency, create a custom provider instance with the `createOpenAICompatible` function from `@ai-sdk/openai-compatible`:

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';

const frequency = createOpenAICompatible({
  name: 'frequency',
  baseURL: 'https://llm.scalefrequency.com/v2',
  apiKey: process.env.FREQUENCY_API_KEY,
  supportsStructuredOutputs: true,
  includeUsage: true,
});
```

<Note>
  Create an API key in the [Frequency Console](https://console.scalefrequency.com). Make sure to set the `FREQUENCY_API_KEY` environment variable with your API key. For trial keys, set `baseURL` to `https://sandbox.voice.miraiminds.co/v2`.
</Note>

## Language Models

You can create Frequency models using the provider instance. The first argument is a model ID, for example `google/gemma-4-26b-a4b-it` or `mira-llm`.

```ts
const model = frequency('google/gemma-4-26b-a4b-it');
```

### Example

You can use Frequency language models to generate text with the `generateText` function:

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';
import { generateText } from 'ai';

const frequency = createOpenAICompatible({
  name: 'frequency',
  baseURL: 'https://llm.scalefrequency.com/v2',
  apiKey: process.env.FREQUENCY_API_KEY,
  supportsStructuredOutputs: true,
  includeUsage: true,
});

const { text } = await generateText({
  model: frequency('google/gemma-4-26b-a4b-it'),
  prompt: 'In one sentence: what is UPI?',
});

console.log(text);
```

Frequency language models can also generate text in a streaming fashion with the `streamText` function:

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';
import { streamText } from 'ai';

const frequency = createOpenAICompatible({
  name: 'frequency',
  baseURL: 'https://llm.scalefrequency.com/v2',
  apiKey: process.env.FREQUENCY_API_KEY,
  supportsStructuredOutputs: true,
  includeUsage: true,
});

const result = streamText({
  model: frequency('google/gemma-4-26b-a4b-it'),
  prompt: 'Write a short poem about Delhi in autumn.',
});

for await (const textPart of result.textStream) {
  process.stdout.write(textPart);
}
```

See the [Frequency documentation](https://docs.miraiminds.co/v2/llm) for more examples, limits, and pricing.
