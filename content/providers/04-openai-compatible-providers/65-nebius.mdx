# Nebius Token Factory Provider

[Nebius Token Factory](https://tokenfactory.nebius.com/) provides inference for open-source AI models through an OpenAI-compatible API. You can use it with the AI SDK through the `@ai-sdk/openai-compatible` module.

## Setup

The Nebius Token Factory provider is available via the `@ai-sdk/openai-compatible` module. You can install it with:

<InstallPackages packages="@ai-sdk/openai-compatible" />

## Provider Instance

To use Nebius Token Factory, create a custom provider instance with the `createOpenAICompatible` function:

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';

const nebius = createOpenAICompatible({
  name: 'nebius',
  baseURL: 'https://api.tokenfactory.nebius.com/v1/',
  apiKey: process.env.NEBIUS_API_KEY,
});
```

<Note>
  Create an API key in [Nebius Token Factory](https://tokenfactory.nebius.com/).
  Make sure to set the `NEBIUS_API_KEY` environment variable with your API key.
</Note>

## Language Models

You can create Nebius Token Factory models using the provider instance. For example, to use `deepseek-ai/DeepSeek-R1-0528`:

```ts
const model = nebius('deepseek-ai/DeepSeek-R1-0528');
```

### Example

You can use Nebius Token Factory language models to generate text with the `generateText` function:

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';
import { generateText } from 'ai';

const nebius = createOpenAICompatible({
  name: 'nebius',
  baseURL: 'https://api.tokenfactory.nebius.com/v1/',
  apiKey: process.env.NEBIUS_API_KEY,
});

const { text } = await generateText({
  model: nebius('deepseek-ai/DeepSeek-R1-0528'),
  prompt: 'Explain what an OpenAI-compatible API is in one sentence.',
});

console.log(text);
```

Nebius Token Factory language models can also generate text in a streaming fashion with `streamText`.
