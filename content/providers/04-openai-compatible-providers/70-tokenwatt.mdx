# TokenWatt Provider

[TokenWatt](https://www.tokenwatt.io/) provides open-weight models through an
OpenAI-compatible API. You can use its Chat Completions endpoint with the AI
SDK through the `@ai-sdk/openai-compatible` module.

## Setup

Install the OpenAI Compatible provider:

<InstallPackages packages="@ai-sdk/openai-compatible" />

Create a [TokenWatt API key](https://www.tokenwatt.io/api.html) and set it as a
server-side environment variable:

```bash
export TOKENWATT_API_KEY=your-api-key
```

## Provider Instance

Create a TokenWatt provider instance with `createOpenAICompatible`:

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';

const tokenwatt = createOpenAICompatible({
  name: 'tokenwatt',
  apiKey: process.env.TOKENWATT_API_KEY,
  baseURL: 'https://api.tokenwatt.io/v1',
  includeUsage: true,
  supportsStructuredOutputs: true,
});
```

The `apiKey` setting sends the key as a Bearer token in the `Authorization`
header. `includeUsage: true` requests usage information in streaming
responses.

## Language Models

Create a language model by passing its ID to the provider instance. The public
[`GET /v1/models`](https://api.tokenwatt.io/v1/models) endpoint lists the
available model IDs. For example:

```ts
const model = tokenwatt('qwen/qwen3-coder-30b-a3b-instruct');
```

## Generate Text

Use `generateText` to generate text with a model:

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';
import { generateText } from 'ai';

const tokenwatt = createOpenAICompatible({
  name: 'tokenwatt',
  apiKey: process.env.TOKENWATT_API_KEY,
  baseURL: 'https://api.tokenwatt.io/v1',
  includeUsage: true,
});

const { text } = await generateText({
  model: tokenwatt('qwen/qwen3-coder-30b-a3b-instruct'),
  prompt: 'Reply with the single word: ready',
});

console.log(text);
```

## Stream Text

Use `streamText` to stream generated text:

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';
import { streamText } from 'ai';

const tokenwatt = createOpenAICompatible({
  name: 'tokenwatt',
  apiKey: process.env.TOKENWATT_API_KEY,
  baseURL: 'https://api.tokenwatt.io/v1',
  includeUsage: true,
});

const result = streamText({
  model: tokenwatt('qwen/qwen3-coder-30b-a3b-instruct'),
  prompt: 'Count from 1 to 5, separated by spaces.',
});

for await (const textPart of result.textStream) {
  process.stdout.write(textPart);
}
```

TokenWatt models that support tool calling and JSON Schema can use those
features through the OpenAI-compatible endpoint. Set
`supportsStructuredOutputs: true` when creating the provider to enable
structured outputs.
