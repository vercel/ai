# TokenLab Provider

[TokenLab](https://tokenlab.sh?utm_source=vercel-ai) is an AI gateway that provides access to models from multiple providers through one OpenAI-compatible API. You can use its Chat Completions endpoint with the AI SDK through the `@ai-sdk/openai-compatible` module.

## Setup

The TokenLab provider is available via the `@ai-sdk/openai-compatible` module as it is compatible with the OpenAI API. You can install it with:

<InstallPackages packages="@ai-sdk/openai-compatible" />

## Provider Instance

To use TokenLab, create a custom provider instance with the `createOpenAICompatible` function from `@ai-sdk/openai-compatible`:

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';

const tokenlab = createOpenAICompatible({
  name: 'tokenlab',
  baseURL: 'https://api.tokenlab.sh/v1',
  apiKey: process.env.TOKENLAB_API_KEY,
});
```

<Note>
  Follow the [TokenLab AI SDK guide](https://tokenlab.sh/docs/en/integrations/vercel-ai-sdk?utm_source=vercel-ai)
  to create an API key. Make sure to set the `TOKENLAB_API_KEY` environment
  variable with your API key.
</Note>

## Language Models

You can create TokenLab models using the provider instance. The first argument is a model ID from the [model catalog](https://tokenlab.sh/en/models?utm_source=vercel-ai), for example `gpt-5.6-terra`.

```ts
const model = tokenlab('gpt-5.6-terra');
```

### Example

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';
import { generateText } from 'ai';

const tokenlab = createOpenAICompatible({
  name: 'tokenlab',
  baseURL: 'https://api.tokenlab.sh/v1',
  apiKey: process.env.TOKENLAB_API_KEY,
});

const { text } = await generateText({
  model: tokenlab('gpt-5.6-terra'),
  prompt: 'Tell me about yourself in one sentence.',
});

console.log(text);
```

TokenLab language models can also generate text in a streaming fashion with the `streamText` function:

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';
import { streamText } from 'ai';

const tokenlab = createOpenAICompatible({
  name: 'tokenlab',
  baseURL: 'https://api.tokenlab.sh/v1',
  apiKey: process.env.TOKENLAB_API_KEY,
});

const result = streamText({
  model: tokenlab('gpt-5.6-terra'),
  prompt: 'Write a short haiku about routing.',
});

for await (const textPart of result.textStream) {
  process.stdout.write(textPart);
}
```

See the [TokenLab AI SDK integration guide](https://tokenlab.sh/docs/en/integrations/vercel-ai-sdk?utm_source=vercel-ai) for more examples.
