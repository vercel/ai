# Vynaris Provider

[Vynaris](https://vynaris.com/) hosts powerful uncensored models for authorized security testing, red-teaming, and research, including Qwen3.8-27B, DeepSeek-V4-Flash, and Qwen3.6-35B-A3B. It exposes them, together with a broader routed model catalog, through an OpenAI-compatible Chat Completions API. You can use it with the AI SDK through the `@ai-sdk/openai-compatible` module.

## Setup

Install the OpenAI Compatible provider:

<InstallPackages packages="@ai-sdk/openai-compatible" />

Create a Vynaris API key and set it as a server-side environment variable:

```bash
export VYNARIS_API_KEY=your-api-key
```

See the [Vynaris documentation](https://vynaris.com/docs) for instructions on creating an API key.

## Provider Instance

Create a Vynaris provider instance with `createOpenAICompatible`:

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';

const vynaris = createOpenAICompatible({
  name: 'vynaris',
  apiKey: process.env.VYNARIS_API_KEY,
  baseURL: 'https://api.vynaris.com/v1',
});
```

The `apiKey` setting sends your key as a Bearer token in the `Authorization` header.

## Language Models

Create a language model by passing a Vynaris model ID to the provider instance. Use `auto` to let Vynaris route the request, or pass a hosted model ID directly:

```ts
const model = vynaris('auto');
const hosted = vynaris('vynaris/qwen3.6-35b-a3b-uncensored');
```

### Generate Text

Use `generateText` to generate text with the model:

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';
import { generateText } from 'ai';

const vynaris = createOpenAICompatible({
  name: 'vynaris',
  apiKey: process.env.VYNARIS_API_KEY,
  baseURL: 'https://api.vynaris.com/v1',
});

const { text } = await generateText({
  model: vynaris('auto'),
  prompt: 'Explain what a red-team exercise is in one sentence.',
});

console.log(text);
```

### Stream Text

Use `streamText` to stream text as it is generated:

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';
import { streamText } from 'ai';

const vynaris = createOpenAICompatible({
  name: 'vynaris',
  apiKey: process.env.VYNARIS_API_KEY,
  baseURL: 'https://api.vynaris.com/v1',
});

const result = streamText({
  model: vynaris('auto'),
  prompt: 'Count from 1 to 5, separated by spaces.',
});

for await (const textPart of result.textStream) {
  process.stdout.write(textPart);
}
```

## Supported Models and Capabilities

This integration uses Vynaris' OpenAI-compatible Chat Completions endpoint for text generation and streaming. Support for tools and other model-specific features depends on the selected model.

The model catalog changes over time. See the [Vynaris model list](https://vynaris.com/models) and [pricing](https://vynaris.com/pricing) for current model IDs and per-token rates.
