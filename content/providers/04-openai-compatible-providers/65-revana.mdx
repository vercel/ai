# Revana Provider

[Revana](https://revana.si/) is an API that puts models from several labs (Claude, Gemini, DeepSeek and others, plus image and video models such as Seedance, Veo, Kling and Nano Banana) behind one key. Its Chat Completions endpoint is OpenAI-compatible, so you can use it with the AI SDK through the `@ai-sdk/openai-compatible` module.

## Setup

Install the OpenAI Compatible provider:

<InstallPackages packages="@ai-sdk/openai-compatible" />

Create a Revana API key in the [Revana dashboard](https://revana.si/dashboard) and set it as a server-side environment variable:

```bash
export REVANA_API_KEY=your-api-key
```

## Provider Instance

Create a Revana provider instance with `createOpenAICompatible`:

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';

const revana = createOpenAICompatible({
  name: 'revana',
  apiKey: process.env.REVANA_API_KEY,
  baseURL: 'https://api.revana.si/v1',
});
```

The `apiKey` setting sends your key as a Bearer token in the `Authorization` header.

## Language Models

Create a language model by passing a Revana model ID to the provider instance:

```ts
const model = revana('claude-haiku-5-5');
```

### Generate Text

Use `generateText` to generate text with the model:

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';
import { generateText } from 'ai';

const revana = createOpenAICompatible({
  name: 'revana',
  apiKey: process.env.REVANA_API_KEY,
  baseURL: 'https://api.revana.si/v1',
});

const { text } = await generateText({
  model: revana('claude-haiku-5-5'),
  prompt: 'Explain what an API gateway does in one sentence.',
});

console.log(text);
```

### Stream Text

Use `streamText` to stream text as it is generated:

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';
import { streamText } from 'ai';

const revana = createOpenAICompatible({
  name: 'revana',
  apiKey: process.env.REVANA_API_KEY,
  baseURL: 'https://api.revana.si/v1',
});

const result = streamText({
  model: revana('claude-haiku-5-5'),
  prompt: 'Count from 1 to 5, separated by spaces.',
});

for await (const textPart of result.textStream) {
  process.stdout.write(textPart);
}
```

## Supported Models and Capabilities

This integration uses Revana's OpenAI-compatible Chat Completions endpoint for text generation and streaming. Support for tools, vision, and other model-specific features depends on the selected model.

The model catalog and prices change over time. The public [`GET /v1/models`](https://api.revana.si/v1/models) endpoint (no key needed) lists every model ID with its current price; text models have `"kind": "text"`.

Image, video and music models are served through Revana's own generations API rather than Chat Completions. See the [Revana API documentation](https://revana.si/docs) for those.
