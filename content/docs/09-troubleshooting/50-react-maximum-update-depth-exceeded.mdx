# React error "Maximum update depth exceeded"

## Issue

I am using the AI SDK in a React project with the `useChat` or `useCompletion` hooks
and I get the following error when AI responses stream in: `Maximum update depth exceeded`.

## Background

Frequent streaming updates can overload rendering, especially on slower devices
or when complex components need updating (e.g. Markdown). `useChat` uses a 50ms
message publication cadence by default. `useCompletion` remains unthrottled by
default.

## Solution

For expensive chat interfaces, increase the `useChat` publication cadence:

### `useChat`

```tsx filename="page.tsx" highlight="2-3"
const { messages, ... } = useChat({
  // Publish message snapshots at most once every 100ms:
  throttle: 100,
})
```

The default is `50`. Set `throttle: 0` only when you intentionally need to
publish every message snapshot without throttling.

For `useCompletion`, enable throttling explicitly:

### `useCompletion`

```tsx filename="page.tsx" highlight="2-3"
const { completion, ... } = useCompletion({
  // Throttle the completion and data updates to 50ms:
  throttle: 50,
})
```
