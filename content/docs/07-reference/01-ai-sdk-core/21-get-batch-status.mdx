# `experimental_getBatchStatus()`

<Note type="warning">
  Text batch support is experimental and the API may change in patch releases.
</Note>

Retrieves the latest status of an asynchronous text batch. For a complete guide
to the batch lifecycle, see [Text Batches](/docs/ai-sdk-core/text-batches).

```ts
import { experimental_getBatchStatus as getBatchStatus } from 'ai';

const status = await getBatchStatus({
  model,
  batch,
});

console.log(status.status, status.requestCounts);
```
