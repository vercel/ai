# `hasRepeatedToolCalls()`

Creates a stop condition that triggers when the requested number of consecutive
steps contain the same tool calls.

The function compares each step as an order-independent collection of tool names
and deterministically serialized inputs. Object key order is ignored. Parallel
calls and duplicate calls are preserved, while changing tool-call IDs are
ignored.

```ts
import { ToolLoopAgent, hasRepeatedToolCalls, isLoopFinished } from 'ai';
__PROVIDER_IMPORT__;

const agent = new ToolLoopAgent({
  model: __MODEL__,
  tools: {
    // your tools
  },
  stopWhen: [isLoopFinished(), hasRepeatedToolCalls(3)],
});
```

### Returns

A `StopCondition` that returns `true` when the last `count` steps repeat the
same tool calls. A step without tool calls breaks the streak.

The condition is evaluated after the threshold step and its tools have
executed. It stops the next model step; it does not prevent the threshold calls
from executing or change the generation's finish reason.

## Examples

### Stop an uncapped repeated loop

```ts
import { ToolLoopAgent, hasRepeatedToolCalls, isLoopFinished } from 'ai';

const agent = new ToolLoopAgent({
  model: yourModel,
  tools: yourTools,
  stopWhen: [isLoopFinished(), hasRepeatedToolCalls(3)],
});
```

### Compare tool results for polling

Set `compareResults` to allow repeated inputs to continue while their outputs
are changing:

```ts
const agent = new ToolLoopAgent({
  model: yourModel,
  tools: {
    checkJobStatus: statusTool,
  },
  stopWhen: hasRepeatedToolCalls(3, {
    compareResults: true,
  }),
});
```

When result comparison is enabled, every tool call in the compared steps must
have a corresponding final tool result or error. Preliminary results are
ignored. Steps with missing or deferred results are not considered repeated.

Inputs, results, or errors that cannot be compared without losing information
do not trigger the condition. Unsupported values include cyclic structures,
`bigint`, functions, symbols, non-finite numbers, sparse arrays, and `Map`,
`Set`, or class instances without a `toJSON` method.
