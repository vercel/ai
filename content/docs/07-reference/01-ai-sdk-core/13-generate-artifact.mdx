# `experimental_generateArtifact()`

<Note>
  Artifact generation is an experimental feature. The API may change in future
  versions.
</Note>

Generates one or more downloadable files using an artifact model. Artifact
models can accept text and file inputs, enabling workflows such as text-to-3D,
image-to-3D, multiview-to-3D, and mesh retopology.

```ts
import { fal } from '@ai-sdk/fal';
import { experimental_generateArtifact as generateArtifact } from 'ai';

const { artifact, artifacts } = await generateArtifact({
  model: fal.artifact('tripo3d/h3.1/text-to-3d'),
  prompt: 'A small house with a red roof and white walls',
});
```
