# `experimental_startTextBatch()`

<Note type="warning">
  Text batch support is experimental and the API may change in patch releases.
</Note>

Starts an asynchronous text-generation batch. For a complete guide to the
batch lifecycle, see [Text Batches](/docs/ai-sdk-core/text-batches).

```ts
import { experimental_startTextBatch as startTextBatch } from 'ai';

const batch = await startTextBatch({
  model: 'openai/gpt-4.1-nano',
  requests: [{ id: 'france', prompt: 'What is the capital of France?' }],
});
```
