# AI_ToolCallNotExecutedError

This error occurs when a tool call was ready to execute but was skipped because of the finish reason of the model call.
Tools are only executed when the model call finishes with `stop` or `tool-calls`.
For other finish reasons, such as `length` when the output token limit cuts off a batch of tool calls, the tool call is resolved with this error instead of being left pending.

The error is reported as the `error` of a `tool-error` part. It is not thrown.

## Properties

- `toolName`: The name of the tool that was not executed
- `toolCallId`: The ID of the tool call that was not executed
- `finishReason`: The finish reason of the model call

## Checking for this Error

You can check if an error is an instance of `AI_ToolCallNotExecutedError` using:

```typescript
import { ToolCallNotExecutedError } from 'ai';

if (ToolCallNotExecutedError.isInstance(error)) {
  // Handle the error
}
```
