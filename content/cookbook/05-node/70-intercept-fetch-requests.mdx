# Intercepting Fetch Requests

Many providers support setting a custom `fetch` function using the `fetch` argument in their factory function.

A custom `fetch` function can be used to intercept and modify requests before they are sent to the provider's API,
and to intercept and modify responses before they are returned to the caller.

Use cases for intercepting requests include:

- Logging requests and responses
- Adding authentication headers
- Modifying request bodies
- Caching responses
- Using a custom HTTP client

## Preserving URL download protection

A fetch wrapper that logs requests, adds authentication, or retries failures
does not provide SSRF protection. When your server fetches URLs supplied by
users, models, tools, or external services, use `@ai-sdk/guarded-fetch` on Node.js
unless your application controls the destinations or already enforces equivalent
protection through its fetch implementation or network egress policy. URL checks
and a separate DNS lookup before fetch do not prevent DNS rebinding.

Wrap the guarded transport for logging or other middleware, and preserve the
request's abort signal and redirect mode. Only attach credentials to explicitly
approved destinations. Provider fetch settings apply to provider requests;
core prompt downloads use `experimental_download`, and transcription and video
downloads use `download: createDownload({ fetch })`. See [Secure URL
Fetching](/docs/advanced/secure-url-fetching) for the configuration examples,
runtime requirements, and connection-pool lifecycle.

## Example

```ts file='index.ts' highlight="5-13"
import { generateText, createGateway } from 'ai';

const gateway = createGateway({
  // example fetch wrapper that logs the input to the API call:
  fetch: async (url, options) => {
    console.log('URL', url);
    console.log('Headers', JSON.stringify(options!.headers, null, 2));
    console.log(
      `Body ${JSON.stringify(JSON.parse(options!.body! as string), null, 2)}`,
    );
    return await fetch(url, options);
  },
});

const { text } = await generateText({
  model: gateway('openai/gpt-6-astra'),
  prompt: 'Why is the sky blue?',
});
```
